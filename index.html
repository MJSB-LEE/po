📍 Locations

Locations are read automatically from the Location column in your PO and GRN files. Names come from the AutoCount Stock Location Listing — upload it again whenever you add a new location in AutoCount.

🏷️ Creditor Name Rules

Group many shop names under one creditor in every report — e.g. every "Shopee …" shop shows as Shopee. The PO's creditor code is used first; these rules only change how the name is shown and grouped.

☁️ Cloud (GitHub)

The data is one locked file on GitHub. Everyone can open the website, but only users who log in with their username + password can read it. To save, a PC needs the GitHub key.

📁 Shared Folder (this PC)

Where this PC saves the data when you click 💾 Save. Each PC chooses it once.

👤 Users

Everyone logs in so the portal knows who uploaded and saved the data. The user list is saved together with the data (shared folder or cloud).

🕘 Activity Log

Every save to the shared folder: who, when and what was uploaded.

🏢 Companies

Each company is detected from the name at the top of the AutoCount CSV, and its data is kept separately in the shared data file. Upload another company's files and they are added here without touching the others.

🏷️ Report Heading

Name printed at the top of every report for the company you are viewing.
